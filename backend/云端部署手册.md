## 2. 一键部署脚本（服务器端执行）

把以下内容保存为 `deploy.sh`，上传到服务器后 `chmod +x deploy.sh && sudo ./deploy.sh` 即可。

```bash
#!/usr/bin/env bash
# deploy.sh —— 智愿云服务器一键部署（Ubuntu 22.04 / Debian 12）
# 功能：apt 依赖、Python 3.11、venv 装库、MySQL(可选)、Nginx、systemd 守护、日志轮切
set -euo pipefail

PROJECT_DIR=/opt/zhiyuan
PORT=8000
WORKERS=2       # 2C4G 起步，加核加 worker
DOMAIN="${1:-your-domain.com}"   # 可选：传你的域名（会自动配 HTTPS）

echo "==== 1) Install system deps ===="
apt-get update -y
apt-get install -y --no-install-recommends \
  python3 python3-venv python3-pip python3-dev \
  nginx curl ca-certificates
# (可选) 服务器本地装 MySQL：apt-get install -y mysql-server-8.0

echo "==== 2) Create project & venv ===="
mkdir -p "$PROJECT_DIR" /var/log/zhiyuan
# —— 把你本地整个项目上传到 /opt/zhiyuan（推荐 scp / rsync） ——
# scp -r d:/Pycharm/2026.9.3/新建文件夹/* root@SERVER_IP:/opt/zhiyuan/
chown -R www-data:www-data "$PROJECT_DIR"

cd "$PROJECT_DIR"
python3 -m venv .venv
. .venv/bin/activate
pip install --upgrade pip
pip install -r backend/requirements.txt

echo "==== 3) Write .env ===="
# 服务器实际部署：请把 <<EOF...EOF 里的值换成你的真实凭据！
cat > .env <<'EOF'
LLM_API_KEY=sk-YOUR_DEEPSEEK_KEY
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat
LLM_TIMEOUT=60

MYSQL_HOST=127.0.0.1
MYSQL_PORT=3306
MYSQL_USER=zhiyuan
MYSQL_PASSWORD=CHANGE_ME_TO_STRONG_PW
MYSQL_DATABASE=zhiyuan

APP_SECRET_KEY=RUN_python_>>>_import_secrets_;print(secrets.token_hex(32))_<<<
JWT_EXPIRE_MINUTES=10080
EOF
chmod 600 .env

echo "==== 4) systemd 服务 ===="
cat > /etc/systemd/system/zhiyuan.service <<UNIT
[Unit]
Description=Zhiyuan AI App Backend (gunicorn + uvicorn workers)
After=network.target nginx.service

[Service]
Type=notify
User=www-data
Group=www-data
WorkingDirectory=/opt/zhiyuan/backend
Environment="PATH=/opt/zhiyuan/.venv/bin"
ExecStart=/opt/zhiyuan/.venv/bin/gunicorn \
    -k uvicorn.workers.UvicornWorker \
    -w $WORKERS \
    --bind 127.0.0.1:$PORT \
    --timeout 120 \
    --log-level info \
    --error-logfile /var/log/zhiyuan/gunicorn.error.log \
    --access-logfile /var/log/zhiyuan/gunicorn.access.log \
    main:app
Restart=always
RestartSec=3
StandardOutput=append:/var/log/zhiyuan/app.out.log
StandardError=append:/var/log/zhiyuan/app.err.log

[Install]
WantedBy=multi-user.target
UNIT
systemctl daemon-reload
systemctl enable --now zhiyuan

echo "==== 5) Nginx 反代 + 静态 ===="
cat > /etc/nginx/sites-available/zhiyuan <<'NGX'
server {
    listen 80;
    server_name _;
    # 如你有域名，把上面改成 server_name your-domain.com;

    client_max_body_size 2M;

    # 静态资源（前端）直接由 Nginx 返回，更省资源
    location = / {
        root /opt/zhiyuan;
        try_files /zhiyuan_app.html =404;
        add_header Cache-Control "no-cache";
    }
    location ~ ^/(zhiyuan_app\.html|高考志愿线框图\.html|data\.js|test_data\.js|.*\.md)$ {
        root /opt/zhiyuan;
        add_header Cache-Control "public, max-age=300";
    }

    # API 反向代理到 gunicorn
    location /api/ {
        proxy_pass         http://127.0.0.1:8000;
        proxy_http_version 1.1;
        proxy_set_header   Host              $host;
        proxy_set_header   X-Real-IP         $remote_addr;
        proxy_set_header   X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_set_header   X-Forwarded-Proto $scheme;
        proxy_read_timeout 120s;   # 大模型可能久一点
    }

    # 健康检查
    location = /healthz {
        proxy_pass http://127.0.0.1:8000/api/health;
    }
}
NGX
ln -sf /etc/nginx/sites-available/zhiyuan /etc/nginx/sites-enabled/zhiyuan
rm -f /etc/nginx/sites-enabled/default
nginx -t && systemctl reload nginx

echo "==== 6) (Optional) HTTPS (Let's Encrypt) ===="
if command -v certbot >/dev/null 2>&1; then true; else
  apt-get install -y certbot python3-certbot-nginx
fi
# 如果前面给了域名，自动签证书：
# certbot --nginx -d "$DOMAIN" --redirect --non-interactive --agree-tos -m YOUR_EMAIL

echo "==== DEPLOY DONE ===="
echo "Service status: systemctl status zhiyuan"
echo "Nginx status:   systemctl status nginx"
echo "Log tail:       tail -f /var/log/zhiyuan/app.out.log /var/log/zhiyuan/gunicorn.error.log"
echo "Health check:   curl -s http://127.0.0.1/api/health"
```

## 3. 本地到服务器上传命令

在你的 Windows 电脑上，用 PowerShell（装好 WinSCP/或用 OpenSSH scp）：
```powershell
# 把整个工作区上传到服务器 /opt/zhiyuan
# 记得先删掉本地不需要的大目录，避免传很久（.venv / __pycache__ / logs）
$excludes = @('.venv','__pycache__','logs','_server.log','_*.py','*.pyc')
# 用 rsync（若装了）：
# rsync -avz --exclude={.venv,__pycache__,logs} d:\Pycharm\2026.9.3\新建文件夹\ root@YOUR_SERVER_IP:/opt/zhiyuan/
# 或用 scp：
Compress-Archive -Path 'd:\Pycharm\2026.9.3\新建文件夹\*' `
  -DestinationPath 'd:\Pycharm\2026.9.3\新建文件夹\deploy.zip'
scp 'd:\Pycharm\2026.9.3\新建文件夹\deploy.zip' root@YOUR_SERVER_IP:/tmp/zhiyuan.zip
# 然后服务器解：sudo unzip -o /tmp/zhiyuan.zip -d /opt/zhiyuan
```

## 4. 接入你的作品集网站（两选一，推荐方案 A）

### 方案 A：子路径访问（SEO & 体验最好，适合同源作品集）
在你作品集的 Nginx 加一条 location：
```nginx
location /projects/zhiyuan/ {
  proxy_pass http://127.0.0.1:8000/;
  proxy_set_header Host $host;
  proxy_set_header X-Real-IP $remote_addr;
}
```
然后作品集里放一个项目卡：
```html
<a href="/projects/zhiyuan/" class="project-card">
  <div class="tag">AI / 志愿填报</div>
  <h3>智愿 · AI 高考志愿填报助手</h3>
  <p>考生成绩 + 偏好 → LLM 生成「冲/稳/保/备」四维方案。</p>
  <div class="stack">Python · FastAPI · MySQL · LLM · JWT</div>
</a>
```

### 方案 B：iframe 嵌入（最快上线，作品集和智愿不同服务器）
```html
<iframe
  src="https://YOUR_SERVER_DOMAIN/"
  style="width:100%; height:760px; border:0; border-radius:16px;"
  loading="lazy"
  title="智愿 AI 志愿填报助手"></iframe>
```

⚠️ CORS：上线后把 `backend/main.py` 里的 `allow_origins=["*"]` 改成**只有作品集域名 + 部署域名白名单**（含 `https://你的域名` 和 `http://localhost:8000` 开发用）。

## 5. 三高（6-7 月高峰）落地操作

| 策略 | 操作 |
|------|------|
| 弹性扩容 | 临时加 1-2 台同等配置服务器，Nginx 轮询到多台内网 IP，或用云厂商「负载均衡」 |
| Redis | 装 Redis，院校/专业/省份/前 1 小时热点方案加缓存（redis==5.x + `aioredis`） |
| 限流 | Nginx `limit_req` 对 `/api/data` 限速：1 人 1 分钟最多 3 次；后端再加 LLM 并发信号量 |
| 监控 | 云监控面板设 CPU/内存/带宽告警；接口错误率告警 |
| 容灾 | DB 定期备份（mysqldump 每日备份到云盘）；LLM 不可用时 mock 兜底（代码已做） |

## 6. 常见问题

- **启动后 502 Bad Gateway**：`systemctl status zhiyuan` 看报错，通常是 .env 里 MySQL 连接串不对，或没装 mysqlclient/PyMySQL。
- **注册报 500**：检查 MySQL 数据库是否存在，`.env` 的 `MYSQL_PASSWORD` 是否正确。没有 MySQL 也能用 SQLite fallback（日志会显示 DB engine FALLBACK SQLite）。
- **生成方案超时**：调大 `LLM_TIMEOUT`；或在 plan_service 加「超时 → fallback 到 mock」。
- **.env 写错后不生效**：`sudo systemctl restart zhiyuan`（gunicorn 不会自动读新 env）。
